## 🛠️ Tecnologías

| Tecnología | Uso |
|---|---|
| **Vite** | Build tool — servidor de desarrollo y empaquetado |
| **AOS** | Animaciones de scroll (Animate On Scroll) |
| **JS Vanilla** | Typing effect, contadores animados, cursor personalizado |
| **IntersectionObserver** | Detecta cuando los elementos entran al viewport |
| **requestAnimationFrame** | Animaciones sincronizadas con el renderizado del navegador |
| **GitHub Pages** | Hosting gratuito del sitio estático |

## ✨ Efectos implementados

- **Typing effect** — el badge del hero escribe y borra frases en loop
- **Contadores animados** — los números de las métricas cuentan desde 0 con easing cúbico
- **Cursor personalizado** — punto verde + anillo con lag que se expande en hover
- **Animaciones de scroll** — elementos aparecen suavemente al entrar al viewport

## 🚀 Correr localmente

```bash
# 1. Clonar el repositorio
git clone https://github.com/JulioCesar339/portfolio.git
cd portfolio

# 2. Instalar dependencias
npm install

# 3. Servidor de desarrollo
npm run dev
```

Abre **http://localhost:5173/** en tu navegador.

---

## 📦 Deploy

```bash
npm run deploy
```

Esto compila el proyecto con Vite y publica la carpeta `dist/` en la rama `gh-pages` automáticamente.
